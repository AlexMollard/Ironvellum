# STATUS: complete. All three drawn and kept under tools/art_batches/drawn/ so a
# later run skips them instead of spending quota again. `crown_rays` is the one

# circle mask at 48dp and the crown still reads. `crown` came back with grey

#
# Why the wording below is what it is:
#   * The adaptive mask keeps only the centre 72dp of 108dp, and the installer
#     scales art into that 66% — so a motif that reads at THUMBNAIL size wins,
#     and anything with fine detail or text is wasted.
#   * The icon sits on the dark green ic_launcher_background, so the emblem
#     must be the pale ink, not a dark shape.
#   * No frame: the model likes drawing its own sketch border in the margin,
#     which the mask then slices into a stray arc.
#
# SUFFIX: single centred emblem, massive bold silhouette, thick pale ink strokes on transparency, no frame, no border, no text, no background, readable at 48dp
