# Glossary term table — Chinese, Simplified (`b+zh+Hans`)

One translation per concept, used in every string. Plain column for `key`, themed for `key__t`.
Register: neutral polite common in fitness apps (你, no 您 for the lifter). Count characters, not bytes.

## Voice

- Buttons: "开始", "继续", "保存", "放弃".
- Notifications: "今天的训练在等你".
- Themed narrator (账册): ink/vellum register ("账册绊了一下——片刻后再试").
- Chinese needs no articles/plurals; concept pl forms equal the singular.
- Keep a space between CJK and digits/Latin: "连续 7 天", "102.5 kg".
