# Glossary term table — German (`de`)

One translation per concept, used in every string. Plain column for `key`, themed for `key__t`.
Register: informal *du*, direct, short, warm. German compounds run long — buttons one short word where possible.

## Voice

- Buttons imperative du: "Starten", "Fortsetzen", "Speichern", "Verwerfen".
- Notifications: "Dein Training wartet", never "Sie".
- Themed narrator (das Archiv): ink/vellum register ("Das Archiv ist gestrauchelt — versuch es gleich erneut").
