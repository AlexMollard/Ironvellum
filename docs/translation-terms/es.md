# Glossary term table — Spanish (`es`)

One translation per concept, used in every string. Plain column for `key`, themed for `key__t`.
Register: informal *tú*, direct, short, warm. CJK-style brevity not applicable; Spanish runs long, so
buttons stay one short word where possible.

## Voice

- "Empieza", "Continúa", "Guarda", "Descarta" — imperative tú for buttons.
- Notifications: "Tu entreno de hoy te espera", never formal "usted".
- The Ledger's narrator in themed mode: ink/vellum register ("El Registro tropezó — inténtalo en un momento").
